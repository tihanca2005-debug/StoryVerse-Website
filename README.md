## Website Description
StoryVerse is an e-commerce website that sells both physical books and movies online. The goal is to provide customers with a one-stop shop for entertainment and storytelling.

## Features
- 5 Web Pages: Home, About, Products, Services, Contact
- Semantic HTML5 structure with header, nav, main, section, footer
- Consistent navigation across all pages
- Product catalogue for books and movies
- Service offerings including rentals and delivery
- Responsive CSS styling
